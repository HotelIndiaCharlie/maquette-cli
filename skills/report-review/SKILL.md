---
name: report-review
description: Review a report page by page with rendered evidence, checking layout, typography, chart integrity and unresolved production issues.
---

Inspect the current document and its page count. Read MAQUETTE.md and any brief/guide the user identifies, with confined file tools. Inspect and render every page; if resource limits require batches, say which pages remain unreviewed. Review reading order, hierarchy, margins, clipping, overset, fonts, image links, number/date conventions and chart validation. Distinguish visible evidence from inference and text-only review when vision is unavailable.

Return findings with page numbers, frame labels where available, observed evidence and a suggested correction. Do not silently repair the report or imply an export/accessibility check was run when it was not. Retain normal permissions for any approved follow-up edits.
